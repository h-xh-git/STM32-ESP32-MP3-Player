双板 MP3 播放器 · 引脚接线图 v1.0 · 与固件代码一致

STM32F407VET6 天空星（存储 / 界面 / 按键）＋ ESP32-S3 N16R8（MP3 软解 / I2S 输出）＋ MAX98357A（D 类功放）→ 8Ω 喇叭
接线前必读（4 条）
  • 共地：STM32、ESP32、MAX98357A、5V 电源的 GND 必须全部连在一起，否则串口乱码、音频全是噪声。
  • MAX98357A 用 5V 独立供电（≥1A），不要用 3.3V；它与两块板的信号线是 3.3V 电平，可以直连。
  • 喇叭接 OUT+ / OUT− 差分，OUT− 绝对不能接 GND，也不能把喇叭任一端接地。
  • ESP32 可用 IO：避开 GPIO26–32（OPI PSRAM 占用）、GPIO19/20（原生 USB）、GPIO43/44（UART0 日志/烧录）、GPIO0/3/45/46（strapping）。本方案用的 GPIO5/6/7/8/17/18/48 全部安全。

2 · STM32 天空星 → TFT（ST7789 2.4" SPI 屏）

TFT 丝印STM32 引脚说明
VCC3.3V逻辑供电（模块自带 3.3V 稳压时也可接 5V，按你的模块丝印）
GNDGND共地
SCK / CLKPA5SPI1_SCK
SDA / MOSIPA7SPI1_MOSI（只写，无 MISO）
CSPA4片选（软件控制）
DC / RSPB0数据 / 命令选择
RES / RSTPB1硬件复位
BLK / LEDPB10背光控制（高=亮）。固件时序：上电 -> 面板初始化 + 整屏填黑 -> 外设/文件系统/UI 初始化 -> 画好首帧 -> 最后才拉高开背光，因此上电过程屏幕全黑、不会闪屏或露花屏。
硬件建议：在 BLK 与 GND 之间加一个 10 kΩ 下拉——MCU 复位期间 PB10 是高阻，有下拉才能保证复位/上电瞬间背光一定是灭的（不加的话模块内部若有上拉，上电可能会亮一下）。
TP_* / SDO不接触摸屏与 MISO 未使用

3 · 独立按键与旋转编码器（内部上拉，按下接地）

按键STM32 引脚固件功能
K1PC0播放 / 暂停（全屏歌词页内仍是播放 / 暂停）
K2PC1上一曲（歌单内：上移）
K3PC2下一曲（歌单内：下移）
K4PC3短按：歌单（开 / 关歌单浮层）
K5PC4短按：切换播放模式（顺序 / 单曲 / 随机；歌单内 K4/K5 均为返回 / 关闭）
旋钮 A 相PC6TIM8_CH1（AF3），硬件编码器模式
旋钮 B 相PC7TIM8_CH2（AF3）
旋钮按下 SWPD12按下接地；功能：歌词模式（主界面 = 进入全屏歌词页，歌词页内 = 返回主界面；播放 / 暂停改由 K1 负责）
接法：每个按键 / 旋钮触点一端接对应引脚，另一端接 GND；内部上拉已开，无需外接电阻。旋转编码器每格 4 个计数（ENC_COUNTS_PER_DETENT），旋转 = 音量 ±5，旋钮按下 = 歌词模式开关（播放 / 暂停改为 K1）。
注意：PC5 不接（P1 起就空置）、PC8 不可占用——PC8 是 SDIO_D0，接旋钮按下会和 TF 卡抢数据线，所以按下脚用 PD12。

4 · 按键提示音：有源蜂鸣器（PB8，低电平触发）

蜂鸣器模块STM32 引脚说明
VCC3.3V3 脚有源蜂鸣器模块（VCC / GND / IO），内部自带振荡电路，只占一个 GPIO，不占用任何定时器 / PWM 通道
GNDGND共地
IO / S / 信号PB8低电平触发：PB8 拉低 = 响，拉高 = 静音。固件把 PB8 配成 推挽输出 + 内部上拉，复位 / 浮空期间被上拉钳在高电平，上电不会先“嘀”一声；beep_set_enable(0) 可全局静音。
固件时序：按键 / 旋钮格数 → 30 ms（BEEP_MS_KEY），进出歌单浮层 / 歌词页 → 60 ms（BEEP_MS_ACT）；beep_poll() 在主循环里到点自动关，全程非阻塞、不 delay。
为什么用有源模块：有源蜂鸣器内部自带振荡电路，MCU 只要给一个直流电平就能响；无源蜂鸣器需要 MCU 输出方波载波（要额外占一个定时器通道 + PWM），本项目用有源模块，所以 PB8 只做普通推挽输出即可。
引脚不冲突：TFT 用 PB0 / PB1 / PB10，按键 / 旋钮用 PC0-PC4 / PC6 / PC7 / PD12，SDIO 用 PC8-PC12 / PD2 / PD3，USART2 用 PA2 / PA3，PB8 单独留给提示音。

6 · STM32 ↔ ESP32-S3 串口互联（交叉接线）

STM32（USART2）方向ESP32-S3（Serial1）说明
PA2 (TX)→GPIO17 (RX)STM32 发给 ESP32 的帧（音频数据 + 状态）
PA3 (RX)←GPIO18 (TX)ESP32 发给 STM32 的帧（控制 + 音频请求）
GND—GND必须共地
参数：1 000 000 bps，8 数据位 / 无校验 / 1 停止位（不要设 460800，带宽不够会爆音）。两边都是 3.3V 电平，直连，不要串 5V。

7 · ESP32-S3 → MAX98357A → 喇叭

MAX98357AESP32-S3说明
BCLKGPIO5I2S 位时钟
LRC / LRCLK / WSGPIO6I2S 左右声道时钟
DINGPIO7I2S 数据（MAX98357A 无需 MCLK）
SD / MODE接 3V3注意：这不是单纯的使能脚，它同时选声道。电压 <0.16V = 关断；0.16~0.77V = 输出 (L+R)/2；0.77~1.4V = 只出右声道；>1.4V = 只出左声道。引脚内部自带 100kΩ 下拉，所以想落在中间档必须外加对 Vin 的上拉电阻。
最终接法：SD 直接接 3V3（>1.4V，只出左声道）。固件已把立体声下混成单声道并复制到左右两槽，因此不丢右声道内容。
实测：用 GPIO8 经 560kΩ 驱动 SD 时喇叭全程沙沙——该节点是高阻分压点，电平不稳会让功放在声道模式间来回跳；硬接 3V3 后干净。
VIN5V独立 5V ≥1A（功放瞬时电流大）
GNDGND共地
GAIN不接实测本机悬空 = 9dB，也是当前推荐接法。若大音量仍破音，想再多 6dB 余量就把它改成 3dB 档：GAIN 经 100kΩ 接 Vin（注意：把 GAIN 直接接 GND 是 12dB，会更响更破，别接错）。悬空 = 9dB（官方增益表，改动后需重新上电：15dB = GAIN 经 100kΩ 接 GND；12dB = GAIN 直接接 GND；9dB = GAIN 悬空（本机实测采用）；6dB = GAIN 直接接 Vin；3dB = GAIN 经 100kΩ 接 Vin（余量最大档））
OUT+ / OUT−喇叭 + / −差分输出，OUT− 不得接地
